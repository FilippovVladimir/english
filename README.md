# Talk Like a Native — разговорный английский

Личный сайт для изучения разговорных фраз, сленга и мата на английском — чтобы понимать фильмы, сериалы и игры.

- **767 фраз** в 19 категориях: перевод, тип (прямой перевод / запомнить целиком), частота, регистр (от нейтрального до мата), пояснение, дословный перевод, примеры и похожие варианты
- **1000 слов** из «1000 слов на все случаи жизни» с транскрипцией
- **143 неправильных глагола**: таблица, режим самопроверки (скрытые формы), тренажёр с вводом форм, группы по типу
- **24 правила грамматики**: объяснение, формулы, примеры с озвучкой, «как в фильмах», типичные ошибки, мини-тест
- Карточки с интервальным повторением (можно вводить ответ с клавиатуры), квиз: «Ситуация», «На слух», перевод
- Фраза дня, цель на день, график активности за неделю, озвучка, избранное, свои фразы, экспорт/импорт
- Тема автоматически следует настройке системы. Работает офлайн и ставится на телефон как приложение

## Как открыть на ПК без интернета
Двойной клик по `index.html`. Всё работает, кроме офлайн-кэша (он и не нужен).

## Публикация на GitHub Pages (без командной строки)
1. Зайди на github.com → **New repository** → название, например `english` → **Public** → Create.
2. На странице репозитория нажми **uploading an existing file** и перетащи ВСЁ содержимое этой папки,
   **кроме PDF** (он большой, и его нельзя выкладывать публично): `index.html`, `app.js`, `styles.css`,
   `manifest.webmanifest`, `sw.js`, `.nojekyll`, папки `data` и `icons`. → **Commit changes**.
   (Чтобы увидеть скрытый `.nojekyll` в Finder: Cmd+Shift+.)
3. **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты сайт будет по адресу `https://<твой-логин>.github.io/english/`.

> Бесплатный GitHub Pages требует публичный репозиторий. Адрес никто не найдёт случайно, но технически он открыт.

## Установка на телефон
- **iPhone (Safari):** открой сайт → «Поделиться» → «На экран „Домой“».
- **Android (Chrome):** меню ⋮ → «Добавить на главный экран» / «Установить приложение».

После первого открытия сайт работает и без интернета.

## Синхронизация телефона и ПК
**Прогресс → Синхронизация**: создаёшь на GitHub ключ с доступом только к Gist (ссылка с готовыми настройками есть на сайте)
и вставляешь его на каждом устройстве. Прогресс, избранное и свои фразы хранятся в приватном Gist и синхронизируются
автоматически: через несколько секунд после занятий и при открытии сайта. Изменения с разных устройств объединяются.
Запасной вариант без ключа — **Экспорт / Импорт** файла.

## Как добавить фразы
- Быстро: вкладка **Прогресс → Добавить свою фразу** (хранится на устройстве).
- Навсегда в базу: дописать в любой файл `data/phrases-*.js` объект по образцу (формат описан в `data/categories.js`),
  затем в `index.html` поменять `?v=2` на `?v=3` и в `sw.js` — `VERSION`, чтобы телефоны подтянули обновление.

## Горячие клавиши (ПК)
`/` — поиск · в карточках: `Пробел` — перевернуть, `1` `2` `3` — оценка, `S` — озвучить · в квизе: `1`–`4` — ответ, `Enter` — дальше.
